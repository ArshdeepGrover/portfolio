# 🚀 Start Here - Quick Guide

## ✅ Setup Complete!

Your Sanity CMS blog is fully configured and ready to use.

---

## 🎯 To Start Working:

### Terminal 1 - Start Sanity Studio

```bash
cd personal-blogs
npm run dev
```

Opens at: **http://localhost:3333**

### Terminal 2 - Start Angular App

```bash
npm start
```

Opens at: **http://localhost:4200**

---

## 📝 Create Your First Post

1. Open **http://localhost:3333**
2. Click **"Blog"** → **"Create"**
3. Fill in the form and click **"Publish"**
4. Visit **http://localhost:4200/blog** to see it!

---

## ⚠️ Important: Configure CORS

Before your Angular app can fetch posts:

1. Go to https://www.sanity.io/manage
2. Select **"Personal Blogs"** project
3. Go to **API** → **CORS Origins**
4. Add: `http://localhost:4200`
